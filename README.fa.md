# Smart Music Tagger

### پاک‌سازی متادیتای فایل‌های موسیقی و تغییر نام آن‌ها با هوش مصنوعی

[English](README.md) | [فارسی](README.fa.md)

---

Smart Music Tagger با استفاده از هوش مصنوعی نام فایل‌های موسیقی را تحلیل می‌کند، متادیتای دقیق استخراج می‌کند، تگ‌های فایل را پاک‌سازی و بازنویسی می‌کند و فایل‌ها را با قالبی یکپارچه تغییر نام می‌دهد.

این پروژه دو رابط کاربری مستقل دارد که هر دو از یک هسته پردازشی مشترک استفاده می‌کنند:

- **CLI**
- **رابط گرافیکی وب (Web GUI)**

---

## ویژگی‌ها

- استخراج متادیتا با استفاده از API سرویس Groq
- حذف کامل تگ‌های قدیمی پیش از نوشتن اطلاعات جدید
- تغییر نام فایل‌ها به قالب `Artist - Song.ext`
- پشتیبانی از فرمت‌های MP3، FLAC، WAV، M4A و OGG
- استفاده مشترک CLI و رابط وب از یک هسته پردازشی
- ثبت گزارش (Log) خوانا از هر اجرا
- معماری ماژولار و قابل توسعه

## نصب

### پیش‌نیازها

- Python 3.8 یا بالاتر
- pip
- یک کلید API از Groq

1. دریافت پروژه

```bash
git clone https://github.com/parsasafaie/smart-music-tagger.git
cd smart-music-tagger
```

2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

3. ایجاد فایل تنظیمات

```bash
cp .env.example .env
```

4. ویرایش فایل `.env`

```env
GROQ_API_KEY=your_groq_api_key
GROQ_API_URL=https://api.groq.com/openai/v1
GROQ_MODEL=groq/compound-mini
GROQ_REQUEST_DELAY_SECONDS=5
MUSIC_DIRECTORY=C:/Users/YourName/Music
```

> فایل `.env` را خصوصی نگه دارید؛ این فایل شامل کلید API شما است.

## پیکربندی

نسخه CLI تنظیمات را از فایل `.env` می‌خواند. رابط وب نیز همان مقادیر را از طریق فرم گرافیکی دریافت می‌کند.

| متغیر | ضروری | توضیح |
|-------|:-----:|-------|
| `GROQ_API_KEY` | بله | کلید API سرویس Groq |
| `GROQ_API_URL` | بله | آدرس API سرویس Groq |
| `GROQ_MODEL` | بله | نام مدل |
| `GROQ_REQUEST_DELAY_SECONDS` | خیر | فاصله زمانی بین درخواست‌های API |
| `MUSIC_DIRECTORY` | بله | مسیر پوشه فایل‌های موسیقی |

## نحوه استفاده

هر دو رابط دقیقاً از یک فرایند پردازش استفاده می‌کنند.

### CLI

تنظیمات از فایل `.env` خوانده می‌شوند.

```bash
python cli_main.py
```

### رابط وب

برنامه Flask را اجرا کنید.

```bash
python gui_main.py
```

سپس در مرورگر باز کنید:

```
http://127.0.0.1:5000
```

فرم را تکمیل کرده و روی **Start Tagging** کلیک کنید.

تنظیمات قابل استفاده:

| گزینه | مقدار پیش‌فرض | توضیح |
|--------|---------------|-------|
| `--host` | `127.0.0.1` | آدرس اتصال |
| `--port` | `5000` | شماره پورت |
| `--debug` | غیرفعال | فعال‌سازی حالت Debug در Flask |

> به‌صورت پیش‌فرض رابط وب فقط از طریق `127.0.0.1` در دسترس است. کلید API ذخیره یا در پاسخ‌های برنامه نمایش داده نمی‌شود.

## متادیتای نوشته‌شده

برای هر فایل، اطلاعات زیر نوشته می‌شود:

- نام آهنگ
- نام هنرمند یا هنرمندان
- نام آلبوم
- ژانر
- سال انتشار
- Album Artist
- شماره ترک (در صورت وجود)

پیش از نوشتن اطلاعات جدید، تمام متادیتای قبلی حذف می‌شود و فیلدهای نامشخص هرگز حدس زده نمی‌شوند.

## معماری

Smart Music Tagger از معماری ماژولار و لایه‌ای استفاده می‌کند. هر دو رابط CLI و وب از `TaggerService` مشترک استفاده می‌کنند تا منطق پردازش از رابط کاربری مستقل باقی بماند.

```text
       cli_main.py                gui_main.py
            │                         │
            └────────────┬────────────┘
                         ▼
                  TaggerService
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
    FileScanner     FileProcessor    FileRenamer
                         │
                GroqClient + MetadataWriter
                         │
                       Logger
```

برای آشنایی بیشتر با ساختار پروژه، فایل [`ARCHITECTURE.md`](ARCHITECTURE.md) را ببینید.
