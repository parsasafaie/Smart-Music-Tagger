# Smart Music Tagger — راهنمای فارسی

[English](README.md) | **فارسی**

## نمای کلی

اسمارت میوزیک تِگِر یک اپلیکیشن خط‌فرمانیِ باکیفیت و آمادهٔ استفاده است که به‌صورت خودکار کارهای زیر را انجام می‌دهد:
- نام فایل‌های موسیقی را با هوش مصنوعی (Groq API) تحلیل می‌کند
- متادیتای دقیق موسیقی را استخراج می‌کند
- تگ‌های متادیتای فایل را به‌روزرسانی می‌کند
- فایل‌ها را در قالبی یکدست تغییر نام می‌دهد

## امکانات

- استخراج متادیتای مبتنی بر هوش مصنوعی با استفاده از Groq API
- پشتیبانی از فرمت‌های MP3، FLAC، WAV، M4A، OGG
- رابط خط فرمانی زیبا با خروجی رنگی
- سیستم لاگ‌گیری جامع
- معماری ماژولار و قابل‌توسعه
- پیکربندی از طریق فایل `.env`

## نصب

### پیش‌نیازها
- پایتون ۳.۸ به بالا
- pip

### راه‌اندازی

۱. مخزن را کلون کرده و وارد آن شوید:
```bash
git clone https://github.com/parsasafaie/smart-music-tagger.git
cd smart-music-tagger
```

۲. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

۳. ساخت و پیکربندی فایل `.env`:
```bash
cp .env.example .env
```

۴. فایل `.env` را با مقادیر واقعی خود پر کنید (به بخش [پیکربندی](#پیکربندی) مراجعه کنید):
```env
GROQ_API_KEY=your_actual_groq_api_key
GROQ_API_URL=https://api.groq.com/openai/v1
GROQ_MODEL=groq/compound-mini
GROQ_REQUEST_DELAY_SECONDS=3
MUSIC_DIRECTORY=C:/Users/YourName/Music
```

## استفاده

اجرای برنامه با دستور:
```bash
python main.py
```

برنامه کارهای زیر را انجام می‌دهد:
۱. پوشهٔ موسیقی پیکربندی‌شده را اسکن می‌کند
۲. نام هر فایل را با هوش مصنوعی تحلیل می‌کند
۳. متادیتا (هنرمند، آلبوم، ژانر، سال) را استخراج می‌کند
۴. تگ‌های متادیتای فایل را به‌روزرسانی می‌کند
۵. فایل‌ها را به این قالب تغییر نام می‌دهد: `Artist - Song.ext`
۶. یک فایل لاگ تفصیلی تولید می‌کند

## پیکربندی

### پیکربندی‌های موردنیاز

- **GROQ_API_KEY** — کلید API گروک شما (از https://console.groq.com/keys دریافت کنید)
- **GROQ_API_URL** — نقطهٔ پایانی API گروک (معمولاً `https://api.groq.com/openai/v1`)
- **GROQ_MODEL** — نام مدل گروک (پیش‌فرض: `groq/compound-mini`، سبک با جستجوی وب)
- **GROQ_REQUEST_DELAY_SECONDS** — حداقل فاصلهٔ زمانی میان درخواست‌ها به گروک (پیش‌فرض: `3`)
- **MUSIC_DIRECTORY** — مسیر پوشهٔ موسیقی شما

## فرمت‌های صوتی پشتیبانی‌شده

- **MP3** — MPEG Audio Layer III
- **FLAC** — Free Lossless Audio Codec
- **WAV** — Waveform Audio File Format
- **M4A** — MPEG-4 Audio
- **OGG** — Ogg Vorbis

## متادیتای استخراج‌شده

هوش مصنوعی متادیتاهای زیر را استخراج می‌کند:
- نام آهنگ
- نام هنرمند(ها) (از چند هنرمند پشتیبانی می‌کند)
- نام آلبوم
- ژانر
- سال انتشار
- هنرمند آلبوم (در صورت تفاوت)
- شماره ترک

## پردازش هوش مصنوعی

هوش مصنوعی (`groq/compound-mini`، با جستجوی وب برای راستی‌آزمایی) هر نام فایل را به این شکل پردازش می‌کند:
۱. حذف تگ‌های بیت‌ریت (۱۲۸kbps، ۳۲۰kbps و غیره)
۲. حذف نام سایت‌های دانلود و تگ‌های منبع/گروه انتشار
۳. پاکسازی تگ‌هایی مثل «Official Video» و «Lyrics»
۴. شناسایی اطلاعات واقعی آهنگ از نام فایل
۵. راستی‌آزمایی متادیتا با جستجوی وب فقط در صورت نیاز
۶. بازگرداندن متادیتای ساخت‌یافته به‌صورت JSON (بدون حدس زدن فیلدهای ناشناخته)

سپس برنامه:
۱. تمام متادیتای موجودِ فایل را پاک می‌کند
۲. فقط تگ‌های استانداردِ راستی‌آزمایی‌شده را می‌نویسد
۳. فایل را به قالب `Artist - Song.ext` تغییر نام می‌دهد

## لاگ‌گیری

تمام نتایج پردازش در فایل `logs/music_tagger_YYYYMMDD_HHMMSS.log` ثبت می‌شوند.

هر رکورد لاگ شامل:
- نام فایل اصلی
- نام فایل جدید
- متادیتای استخراج‌شده
- وضعیت پردازش (موفق/ناموفق)
- هر خطایی که رخ داده است

## مزایای معماری

معماری ماژولار امکان زیر را فراهم می‌کند:
- **آزمون آسان** — هر ماژول به‌صورت مستقل قابل آزمون است
- **یکپارچه‌سازی GUI** — منطق هسته از CLI جدا است
- **یکپارچه‌سازی API** — افزودن لایهٔ REST API آسان است
- **امکانات جدید** — عملیات دسته‌ای، اجرای زمان‌بندی‌شده، افزونه‌ها
- **توسعه‌پذیری** — مسئولیت روشن برای هر ماژول

## مدیریت خطا

این برنامه:
- با فایل‌های مفقود یا نامعتبر به‌خوبی رفتار می‌کند
- از فرمت‌های صوتی پشتیبانی‌نشده عبور می‌کند
- تمام خطاها را برای رفع اشکال لاگ می‌کند
- حتی اگر فایل‌های منفرد شکست بخورند، پردازش را ادامه می‌دهد
- پیام‌های خطای روشنی در CLI و لاگ‌ها ارائه می‌دهد

## رفع اشکال

### پیکربندی بارگذاری نمی‌شود
- مطمئن شوید فایل `.env` در پوشهٔ برنامه وجود دارد
- بررسی کنید که تمام فیلدهای موردنیاز به‌درستی پر شده‌اند

### خطاهای کلید API
- کلید API گروک خود را بررسی کنید
- قالب URL ای‌پی‌آی را بررسی کنید
- مطمئن شوید سهمیهٔ API کافی دارید

### تغییر نام فایل شکست می‌خورد
- مطمئن شوید دسترسی نوشتن در پوشه را دارید
- نام‌های فایل تکراری را بررسی کنید
- بررسی کنید نام فایل نویسهٔ نامعتبر نداشته باشد
